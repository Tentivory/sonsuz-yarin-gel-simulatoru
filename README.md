# Sonsuz Yarın Gel Simülatörü

Bu proje, insanlık tarihinin en büyük varoluşsal krizini çözmek için tasarlanmıştır: Resmi işlemlerde "yarın gel" sözünün sonsuza kadar tekrar edilmesi.

## Nedir Bu?

Bir Python scripti. Çalıştırdığınızda, size sonsuza kadar "yarın gel" der. Farklı tonlarda, farklı bahanelerle, ama hep aynı mesajla. Çünkü gerçek hayatta da öyle.

## Nasıl Çalıştırılır?

```bash
python yarın_gel.py
```

Uyarı: Durdurmak için Ctrl+C'ye basabilirsiniz ama ruhunuzda bir yerde hep devam eder.

## Özellikler

- Sonsuz döngü (evet, gerçekten sonsuz)
- Rastgele bahaneler
- Zaman zaman "bugün de mi?" diye sorma
- Hiçbir şey yapmama konusunda %100 verimlilik

## Neden Bu Proje?

Çünkü birileri sormuştu "ne zaman biter?" diye. Cevap: Yarın.
